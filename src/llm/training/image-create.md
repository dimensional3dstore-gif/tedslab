# Creating Images

Before generating an image, define its purpose, subject, composition, aspect ratio, and intended use. Prefer original visual concepts and assets the project has permission to use. Avoid copying a living artist's distinctive style or reproducing copyrighted characters and logos.

Review the result for anatomical, scientific, cultural, and accessibility issues. Provide meaningful alt text when the image communicates information; use empty alt text only for decoration. Keep a record of the source and generation method when required by the project.
