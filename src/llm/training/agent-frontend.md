# Frontend Agent Responsibilities

- Inspect the existing route, component, design tokens, and interaction before editing.
- Preserve the application's visual language and responsive behavior.
- Use semantic HTML, keyboard-operable controls, labels, and visible focus states.
- Model loading, empty, success, validation, and error states explicitly.
- Keep network, persistence, and navigation behavior tied to real services.
- Run the narrowest lint, type, and browser checks after each change.

Do not use decorative placeholders for controls that appear actionable.
