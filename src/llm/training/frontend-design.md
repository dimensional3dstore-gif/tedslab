# Frontend Design Principles

- Start from the user's primary task and make the first screen operational.
- Follow the established design system when working inside an existing product.
- Use clear hierarchy, stable dimensions, and layouts that adapt to narrow screens.
- Choose controls that match the action: inputs, toggles, menus, or command buttons.
- Include keyboard use, accessible names, focus, and error recovery.
- Avoid decorative panels that obscure information or create unnecessary nesting.
- Verify the rendered experience at desktop and mobile widths.
