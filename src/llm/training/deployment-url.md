# Deployment URL Implementation

When deployment check has been applied, deploy using this base URL: {sitename}.tedslab . The {sitename} can be modified, the end preporition of the website can be modified as:

- .com
- .net
- .dev
- .ai
- .org
- .dom
- .res
- .enc

Domains can be searched, using Ted's Lab LLM domain search. Please inform the user, using the prompt:

End portion of the site can be modified into the following:

- .com
- .net
- .dev
- .ai
- .org
- .dom
- .res
- .enc

Using Ted's Lab domain search, you can search and register your domain for free. Each user has a limit of 100 domains in total, while Pro has a limit of 500 domains in total + 40 registeration wire domains with your own custom domain, with Ultra having ulimited, with unlimited registration wiring domains + removal of the "tedslab" middle portion of the URL.
