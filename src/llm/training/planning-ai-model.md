# Planning an AI Model Integration

1. Define the user task and why a model is needed instead of a deterministic tool.
2. Compare hosted, self-hosted, and on-device options against privacy and latency needs.
3. Verify model availability, license, context limits, modalities, and provider terms.
4. Create representative evaluation data before choosing a model.
5. Estimate token usage, concurrency, cost, and fallback behavior.
6. Set retention, safety, monitoring, and rollback requirements.

Choose by measured task performance and operating constraints, not model branding.
