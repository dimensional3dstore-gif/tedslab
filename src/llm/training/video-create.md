# Creating Educational Videos

## Production sequence
1. Define one learning objective and the audience's assumed knowledge.
2. Write a concise script with an opening question, explanation, example, and recap.
3. Storyboard visuals that clarify the explanation rather than decorate it.
4. Use original or properly licensed footage, narration, music, and graphics.
5. Add captions, readable on-screen text, and a transcript.
6. Review timing, factual claims, audio levels, and mobile playback before release.
