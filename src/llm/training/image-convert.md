# Image Conversion

1. Inspect the input format, dimensions, color profile, and animation state.
2. Confirm the target format supports the required transparency and quality.
3. Resize only when requested; preserve aspect ratio unless a crop is intentional.
4. Set an explicit quality or compression target and compare the output visually.
5. Preserve attribution and licensing information where applicable.
6. Remove sensitive metadata only when appropriate and report that change.

Never overwrite the source until the converted file has been validated.
