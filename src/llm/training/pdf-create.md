# Creating PDFs

## Workflow
1. Confirm the audience, page size, reading order, and required content.
2. Use a maintained PDF library; keep layout data separate from rendering logic.
3. Embed or reference fonts and images with appropriate rights and licenses.
4. Add document title, language, headings, links, and accessible reading order.
5. Reopen the generated file and verify page count, text extraction, links, and clipping.

Do not describe a PDF as accessible until it has been checked with assistive technology.
