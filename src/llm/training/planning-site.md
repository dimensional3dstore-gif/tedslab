# General Planning

When planning to create the site make sure to brainstorm:

- The database, what must need the SQL database within the code structure
- How the pages are going to work
- Whether if pages' functions all work properly, including authentication and API imports and exports.

When given an prompt that suggests AI might be used, but no API key has been identified, set a files and folders for:

- API key file
- API key rendering files and folders

Make sure that code languages vary depending on the application being built:

- Website: Next.js, SQL
- App: Swift (for mac), C#, C++
- Operating System: Rust, C, C#, C++, Assembly, Linux
