# Homepage Agent Responsibilities

The homepage agent maintains the entry point into the learning product.

- Lead with the encyclopedia and the next useful action, not a feature pitch.
- Make search, subjects, and recent learning paths easy to reach.
- Use real article or subject imagery with appropriate alternative text.
- Keep featured content current and links connected to valid routes.
- Test keyboard navigation, mobile layout, empty content, and loading states.
- Avoid claiming personalization or data freshness unless the service supports it.
